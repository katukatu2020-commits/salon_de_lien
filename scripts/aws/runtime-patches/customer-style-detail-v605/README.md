# Customer Style Detail v605

Refines the customer-facing style detail without changing store publishing or editing.

- Shows the stylist once, in the full profile block below the gallery.
- Keeps the style title and service menu above the gallery without a duplicate stylist card.
- Removes Hotpepper/source attribution from the customer view while retaining the source internally and in the staff view.
- Uses a contained, aspect-ratio gallery with explicitly bounded photo cells so images cannot overlap following text in mobile Safari or desktop browsers.

The release is layered only on the locked v604 image. Receipt POS, daily sales print, style metadata, customer booking, favorites, and stamp rewards remain unchanged.
