# Daily sales complete print v541

Prints the complete daily sales report instead of the horizontally scrolled screen table.

- Clones the loaded daily summary into a print-only document.
- Restores every daily row hidden by the legacy detail-print selector.
- Includes every payment and staff column.
- Fits the table to A4 landscape without scrollbars or horizontal clipping.
- Preserves the selected month and staff filter because the rendered report is cloned at print time.
