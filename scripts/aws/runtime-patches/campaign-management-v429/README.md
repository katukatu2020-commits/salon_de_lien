# Campaign management v429

This protected child patch is based on the exact AWS task 428 image.

- Aligns the campaign admin surface with the shared backoffice shell.
- Adds the Campaign tab to every customer workspace tab set.
- Adds organization-scoped campaign edit and soft-delete operations.
- Recalculates campaign recipients when targeting is edited.
- Does not modify the customer mobile bottom navigation or unrelated routes.
