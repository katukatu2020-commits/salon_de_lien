# First-store product tour v405

Adds a concise six-screen guided tour for newly registered store owners. The
tour starts only from the post-registration `registered=1` entry, persists
across page navigation, pauses during billing setup, and can be minimized,
resumed, completed, or dismissed.

The existing staff/menu/reservation-mail setup remains available and is linked
from the tour completion screen when any required setup item is still missing.
