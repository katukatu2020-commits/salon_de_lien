# All dealer order filter v621

Adds a cross-dealer browsing option to the salon purchase-order workspace.

- Adds `すべての発注先` to the dealer dropdown.
- Loads configured products from every active dealer when selected.
- Builds the existing `すべてのメーカー` filter from the combined catalog.
- Keeps each submitted order scoped to exactly one dealer.
- Prevents products from different dealers being mixed in one order.
- Preserves the v620 dealer-code and salon order-history fixes.
