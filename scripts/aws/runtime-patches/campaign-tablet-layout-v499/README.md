# Campaign tablet layout v499

This runtime child release keeps the store-wide campaign behavior from v498 and
removes the legacy 1100px minimum width on the campaign admin route between
768px and 1099px. The desktop sidebar remains available in this range, while the
existing mobile layout continues to apply below 768px.
