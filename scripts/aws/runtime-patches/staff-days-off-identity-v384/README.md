# Staff days off identity v384

スタッフ管理で保存した毎週の定休日を、日別シフト表と予約可否判定へ同じスタッフとして反映するランタイムパッチです。

- `StaffBookingSetting.staffKey` をシフト行へ出力し、定休日表示を氏名ではなく安定したスタッフIDで照合します。
- 旧データとの互換用の氏名照合は、同名スタッフがいる場合には使用しません。
- 定休日未設定の空文字を `0`（日曜）へ変換しないよう、API・店舗設定・予約判定の正規化を統一します。
- 明示的に日曜を選んだ `0` は従来どおり維持します。

本番反映は `deploy-v384.ps1` を使用します。
