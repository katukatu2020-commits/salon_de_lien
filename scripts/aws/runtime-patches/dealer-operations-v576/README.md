# Dealer operations v576

This protected runtime release turns the dealer portal into an operational ordering workspace.

- Shows a unique dealer connection code and lets salon owners request a link with that code.
- Adds dealer-side contracted-salon registration, approval, search, and soft deletion.
- Adds a dealer product catalog with create, edit, search, and soft deletion.
- Makes dealer catalog products orderable from the salon inventory and ordering workspace.
- Exposes delivery-note printing directly from each dealer order while preserving historical documents.
