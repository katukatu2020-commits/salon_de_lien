# Style community controls v469

Protected child-image patch on top of the approved v468 release.

- Lets store staff switch each style post between public and private.
- Keeps private posts in a store-only management list so they can be published again.
- Deletes the community post, likes, and comments without deleting visit history or source photos.
- Shows explicit edit/delete controls on comments owned by the logged-in user.
- Preserves the v468 customer chat lifecycle and tenant/session isolation.
