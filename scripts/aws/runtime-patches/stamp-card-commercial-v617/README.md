# Stamp Card Commercial v617

Redesigns the customer stamp card as a compact, store-branded membership card. It preserves the existing store-scoped visit count and reward program while improving progress, milestone, reward, completed-state, and responsive presentation for 1 to 50 stamps.

The patch changes only the customer stamp page renderer and adds one scoped stylesheet. Salon settings, visit counting, checkout, receipt, and POS behavior remain untouched.
