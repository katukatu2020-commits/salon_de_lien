# Sales ledger staff multiselect v542

Replaces the single staff selector in the daily sales summary with an accessible checkbox dropdown.

- All staff are selected by default.
- Any combination of staff can be selected without closing the dropdown.
- Rows, totals, daily detail, and visible staff columns use the same server-side filter.
- Selecting no staff produces an empty report instead of falling back to all staff.
- The current selection is preserved by the v541 A4 landscape print report.

The release is pinned to the protected v541 production image digest.
