# Shared account available login v553

- Applies the same login-ID availability rules to owner-managed shared-account settings and the shared account's own account page.
- Releases login IDs retained only by inactive back-office accounts before assigning them to an active account.
- Excludes inactive rows from back-office login lookup so retired credentials cannot shadow an active account.
- Continues to reject IDs used by an active owner, staff member, manufacturer, or store-shared account in any organization.
- Clarifies that an active store-side account owns an identifier when a rename is rejected.
