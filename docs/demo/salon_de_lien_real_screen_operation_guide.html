操作手順

  1. 管理画面を開く
  2. 今日のCRM視点を見る
  3. 再来店候補・レビュー未回答・ポイント失効間近を確認する
  4. 山田 美咲さんを選ぶ

接客トーク例

今日は山田さんが来店予定。前回カラー後のパサつきが気になっていたので、商品感想と次回ケアを確認します。

この操作で残るデータ

顧客一覧、未対応アクション、来店予定、ポイント、商品提案状況。

次につながること

優先して声をかける既存客を決め、顧客詳細へ進みます。

顧客検索からカルテを開く

操作手順

  1. 検索欄に「山田」と入力
  2. 顧客一覧から山田 美咲さんを選択
  3. 顧客詳細を開く

接客トーク例

山田さん、前回から1か月半くらいですね。前回の内容を確認しながら今日のご提案をしますね。

この操作で残るデータ

検索条件、顧客プロフィール、来店候補の確認。

次につながること

来店前の状態把握とカウンセリングへ進みます。

顧客詳細

次に何をするかを見る

5

操作手順

  1. 最終来店日を見る
  2. 保有ポイントを見る
  3. 前回メニューを見る
  4. 未対応アクションを見る
  5. おすすめアクションを確認する

接客トーク例

山田さんは前回カラーとトリートメント。今日は仕上がり確認と、乾燥対策のホームケアを提案します。

この操作で残るデータ

顧客プロフィール、来店履歴、ポイント口座、次アクション候補。

次につながること

写真・履歴・メニューを見ながら接客内容を決めます。

カウンセリング

写真・履歴・メニューを見ながら接客する

6

操作手順

  1. 写真タブを開く
  2. 前回仕上がりを見る
  3. 履歴タブで悩みを確認
  4. 今回メニューを提案する

接客トーク例

前回より毛先に少し乾燥が出ているので、今日はまとまりを重視して整えますね。

この操作で残るデータ

写真、前回来店、悩み、施術メモ、次回提案理由。

次につながること

今日のメニュー提案を記録します。

施術前

メニュー提案を記録する

7

操作手順

  1. 今日のメニューを選ぶ
  2. 提案理由を入力
  3. 次回目安を入力
  4. 保存する

接客トーク例

45日くらいでケアするときれいに保てるので、次回も同じ流れで見ていきましょう。

この操作で残るデータ

提案メニュー、提案理由、次回目安、スタッフメモ。

次につながること

施術中または仕上げ時の商品提案につながります。

仕上げ

商品提案を記録する

8

操作手順

  1. 商品を選択
  2. 提案理由を入力
  3. 悩みタグを選ぶ
  4. 状態を「サンプルを渡した」にする
  5. 反応を「興味あり」にする
  6. 保存する

接客トーク例

ドライヤー前に毛先中心につけると、広がりが落ち着きやすいです。サンプルをお渡しするので使ってみてください。

この操作で残るデータ

ProductProposal、商品、悩みタグ、状態、反応、メモ。

次につながること

この商品提案に紐づくレビュー依頼を発行できます。

レビュー依頼

商品レビュー依頼QRを発行する

9

操作手順

  1. 商品提案カードからレビュー依頼を押す
  2. QRまたはURLを表示
  3. お客様に案内する
  4. 必要ならURLをコピーする

接客トーク例

使ってみた頃にこのQRから感想を教えてください。回答いただくとポイントも付きます。お名前はメーカーには共有されません。

この操作で残るデータ

ProductReviewRequest、期限付きトークン、レビュー依頼状況。

次につながること

後日、お客様が商品レビューに回答します。

会計

会計時にポイントを案内する

10

操作手順

  1. 保有ポイントを確認
  2. 利用可能ポイントを確認
  3. 今回使うポイントを入力
  4. 会計時ポイント利用を記録する

接客トーク例

山田さん、今480ポイントあります。今日400ポイント使われますか？

この操作で残るデータ

PointTransaction、PointLot消費、利用後残高。

次につながること

ポイント利用履歴が台帳に残り、次回接客でも確認できます。

次回来店

次回クーポンを作成する

11

操作手順

  1. 顧客名を確認
  2. 対象メニューを選ぶ
  3. 割引率を設定
  4. 有効期限を設定
  5. 印刷プレビューを確認
  6. 印刷または共有する

接客トーク例

45日くらいでケアするときれいに保てるので、次回トリートメントに使える限定クーポンをお渡ししますね。

この操作で残るデータ

CouponIssue、識別コード、発行日、有効期限、印刷履歴。

次につながること

次回来店の理由を紙またはお客様ページで渡します。

お客様ページ

ホームケア・提案共有を案内する

12

操作手順

  1. お客様ページを開く
  2. ホームケア内容を確認
  3. 提案共有ページを案内
  4. LINE等で共有する

接客トーク例

今日お話しした乾かし方とサンプルの使い方をまとめています。家で見返せます。

この操作で残るデータ

お客様ページ、ホームケア、限定クーポン、ポイント表示。

次につながること

お客様が後日、レビューやフィードバックへ進めます。

後日

お客様が商品レビューに回答する

13

操作手順

  1. QRからレビュー画面を開く
  2. 使ったかどうかを選ぶ
  3. 満足度を選ぶ
  4. 良かった点・気になった点を選ぶ
  5. 同意して送信する

接客トーク例

商品名はお客様が選びません。サロン側が記録した商品提案に紐づくため、正確な商品レビューになります。

この操作で残るデータ

ProductReview、匿名共有同意、商品別の評価・コメント。

次につながること

回答内容はポイント付与とメーカー向け匿名集計へつながります。

ポイント付与

回答でポイントが付く

14

操作手順

  1. 回答完了
  2. 50pt付与を確認
  3. お客様トップに戻る
  4. 次回来店時に利用する

接客トーク例

レビュー評価の良し悪しではなく、回答へのお礼としてポイントを付与します。

この操作で残るデータ

PointTransaction、ProductReview、ProductReviewRequest answered。

次につながること

次回来店時の会計利用や再来店理由になります。

紹介

フィードバック・紹介につなげる

15

操作手順

  1. 接客後のフィードバックを依頼
  2. 回答で30pt付与
  3. 満足度が高いお客様に紹介コードを案内
  4. 紹介された方の初回来店後に紹介元へポイント付与

接客トーク例

もし周りで美容室を探している方がいたら、この紹介リンクを送っていただけます。

この操作で残るデータ

ContactLog、Referral、紹介ステータス、紹介ポイント候補。

次につながること

既存客から新規相談が生まれます。

オーナー

販促CRMレポートを見る

16

操作手順

  1. レポートを開く
  2. クーポン・レビュー・ポイント・紹介の状況を見る
  3. 未対応タスクを確認する
  4. 次に動かすお客様を決める

接客トーク例

売上だけでなく、既存客施策が回っているかを毎週確認します。

この操作で残るデータ

クーポン発行数、レビュー回答数、ポイント付与数、紹介成立数、未対応タスク。

次につながること

次に動かす既存客を選び、顧客詳細へ戻ります。

メーカー集計

メーカー向け商品集計を見る

17

操作手順

  1. メーカーを選ぶ
  2. 期間を選ぶ
  3. 商品別の提案数・レビュー数を見る
  4. 良かった点・気になった点を見る
  5. 匿名コメントを確認する

接客トーク例

顧客個人情報を出さず、美容室現場の商品反応をメーカーに返せます。

この操作で残るデータ

商品別の匿名・集計データ。顧客名、電話番号、メール、customerId、スタッフ名、来店日時の個票は出ません。

次につながること

商品改善やメーカー連携の提案材料になります。

まとめ

Salon de Lien は、接客の流れの中で既存客を動かす

18
1顧客詳細で状態を把握
2商品提案で店販につなげる
3レビュー依頼で声を集める
4ポイントで再来店の理由を作る
5クーポンで次回予約につなげる
6紹介で新規客を生む
7レポートで未対応を見える化
8メーカー集計で商品反応を収益化

顧客を登録するシステムではなく、既存客との関係を動かすCRMです。
